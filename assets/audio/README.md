# Audio assets

`piano/`: samples of the "Upright Piano KW" (a Kawai upright in a living room, mono, 44.1 kHz,
one velocity layer, every minor third) from the FreePats project, CC0 1.0
(<https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html>, "small" bank, 2019-07-03). The file
name is the note, `s` meaning sharp. They are embedded in the binary by `src/audio/piano.rs`.
