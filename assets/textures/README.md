# Textures

Photographic surface detail, all CC0 from [Poly Haven](https://polyhaven.com) (no attribution
required, credited here anyway): `concrete_pavement` (pavement.jpg), `worn_asphalt` (asphalt.jpg),
`concrete_slab_wall` (wall.jpg), `bitumen` (roof.jpg, currently unused), `metal_plate_02`
(metal.jpg).

`detail.png` is generated by `tools/pack_textures.py`: the high-passed luminance of four of them
packed in RGBA (R pavement, G asphalt, B wall, A metal). It is embedded in the binary and sampled
by `shaders/scene.fs` as detail over the procedural colors, so the palette stays ours.
